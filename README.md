
# PulseBoard - Live Polls For Feedback

## Project Description
PulseBoard is a real-time polling platform where users can create polls and collect live feedback instantly.

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Socket.IO
- Tailwind CSS
